Liar's Poker Assistant allows the user to input their hole cards and the community cards to calculate the survival probabilities of calling and folding. This can potentially help the user in making decisions at the table.

**User inputs:**
Hole Cards (Starting Hand)
Community Cards (Table Cards)
Number of Opponents
Simulation Times (more simulation potentially means better results at the cost of time)
Current Bid (Bullets you put on the table)
Ante (Amount of bullets required to play)

The Calculate button will do calculations for the probabilities.
The Call All-in button will set the ante to 8 and then perform the calculations.
Reset will reset the table to 3 opponents, 1 bullet bid and 2 for ante.
